# v2.0.1win

Windows x64 听写修复版，应用版本 2.0.1。

## 修复

- 结束录音时，将不足 1024 个采样的末尾音频块补静音到标准长度，避免上游返回 `Audio chunk too small to process`。
- 保留末尾录音的实际采样；最多补入约 64 毫秒静音。

## 安装与复测

运行 `typeless-client_2.0.1_x64-setup.exe` 覆盖安装。连接设置沿用原配置。请连续说话 5 秒左右，再点 ✓；确认能得到文字，并在目标输入框测试自动回填。

## 验证范围

本地回归测试已证明修复前末尾块只有 448 字节，修复后是 2048 字节且原始采样不变。Windows 安装包由 GitHub Actions 构建。Windows 11 家庭中文版 x64 实机已验证 Gateway 连接、F9 听写并自动回填到记事本、× 取消、设置页按钮和重启后配置保留。麦克风输入电平未单独读数，听写成功证明录音链路有输入。设置窗托盘定位及再次点击隐藏的问题留待后续修复。
