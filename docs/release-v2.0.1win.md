# v2.0.1win

Windows x64 听写修复版，应用版本 2.0.1。

## 修复

- 结束录音时，将不足 1024 个采样的末尾音频块补静音到标准长度，避免上游返回 `Audio chunk too small to process`。
- 保留末尾录音的实际采样；最多补入约 64 毫秒静音。

## 安装与复测

运行 `typeless-client_2.0.1_x64-setup.exe` 覆盖安装。连接设置沿用原配置。请连续说话 5 秒左右，再点 ✓；确认能得到文字，并在目标输入框测试自动回填。

## 验证范围

本地回归测试已证明修复前末尾块只有 448 字节，修复后是 2048 字节且原始采样不变。Windows 安装包由 GitHub Actions 构建。Windows 实机听写结果需安装后复测。
