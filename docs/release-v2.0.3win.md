# v2.0.3win

Windows x64 再发行版，应用版本 **2.0.3**。功能与 v2.0.2 相同，本版主要补齐开源许可。

## 本版内容

- 仓库与安装包附带 [MIT](../LICENSE) 许可文本。
- NSIS 安装程序在安装过程中展示 MIT 许可；应用资源目录内包含 `LICENSE` 文件。

## 安装

运行 `typeless-client_2.0.3_x64-setup.exe` 覆盖安装。先从托盘退出旧版再装新版。

## 验证

- GitHub Actions 构建 Windows 安装包。
- 安装后可在应用安装目录或 `Resources` 中确认 `LICENSE` 存在。
