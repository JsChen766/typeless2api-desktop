# v2.0.2win

Windows x64 设置窗修复版，应用版本 2.0.2。基于已通过 Windows 11 实机听写和记事本自动回填测试的 v2.0.1。

## 修复

- 托盘单击使用图标所在屏幕和任务栏可用区域定位设置窗，横向居中于托盘图标上方；系统托盘展开区中的图标也作为定位锚点。
- Windows 设置窗失焦时，若鼠标位于托盘图标上，不抢先隐藏窗口，使第二次单击能够可靠地切换为隐藏。
- 听写报错打开设置页时，沿用最近一次托盘图标位置。

## 安装与复测

运行 `typeless-client_2.0.2_x64-setup.exe` 覆盖安装。先从托盘菜单退出旧版，再启动新版。

在 Windows 11 任务栏托盘中分别测试：单击图标显示、再次单击隐藏；展开“隐藏的图标”后再单击客户端图标，确认设置窗出现在该图标上方。最后复测一次 F9 → 说话 → ✓ 自动回填，确认听写未回归。

## 验证范围

本地 Rust 位置计算测试与前端构建已通过，Windows 安装包由 GitHub Actions 构建。Windows 实机托盘交互仍需安装本版后确认。
